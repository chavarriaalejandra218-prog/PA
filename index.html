Módulos

Tres pantallas, una sola base de datos

Cada módulo tiene su propia tabla SQL en Supabase y su interfaz dedicada.

Inventario

Productos con código, categoría, precio y stock. CRUD completo sobre la tabla productos.

Personal

Identidad, nombres, género, teléfono y dirección de cada colaborador en la tabla personal.

Proveedores

Código autogenerado, empresa, representante, encargado, teléfono, dirección y correo.

Cómo funciona

Del login al dato en la nube

1 · Acceso validado

El formulario intercepta el envío, valida las credenciales con Supabase Auth y muestra alertas visuales si algo falla.

2 · Redirección segura

Al autenticarse, el sistema pasa de login.html a inventario.html y bloquea el acceso directo a los módulos sin sesión.

3 · CRUD en la nube

Insertar, consultar, editar y eliminar escriben directamente en PostgreSQL a través de la API de Supabase.
